# Electrical-Distribution-GIS

A comprehensive and modern GIS Electrical Distribution System.
This Distribution System Utility is one of the Distribution Utility in the Philippines
that provides Electricity Specially in Palawan Calamianes Islands.
This is a scalable webapplication that  provides Real-Time Interactions on GIS data
a complete GIS Data that can be use in Planning, analysis and customer Service.

## App Function and Features

### GIS MAP

![GIS MAP](/Frontend/public/gis-map.png)

#### Functionalities

The user can Turn off and Turn on the Substation and Tranformer to Identify the affected downstream components.
It Provides A realtime Interaction on GIS Web map on multiple User.

This GIS interactive map includes the following location and data:

- Substation
- Primary Lines
- Distribution Transformer
- Secondary Lines
- Customers

### DASHBOARD

!['DASHBOARD'](/Frontend/public/dashboard.png)

#### Functionalities (Dashboard)

The dashboard provides additional overview of some data such as:

- Number of inactive, active and total consumer
- table for inactive consumer affected when turning off the substation or transformer where they are connected upstream.
- line length primary line and secondary line group by each substation.
